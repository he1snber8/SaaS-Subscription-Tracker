# Bitasmbl-SaaS-Subscription-Tracker-3b99c3-9b15c1dd694d

## Description
Build a small multi-tenant SaaS subscription tracker using ASP.NET Core and React to evaluate junior full‑stack end‑to‑end problem solving.

## Tech Stack
- ASP.NET Core
- React

## Requirements
- Implement secure multi-tenant CRUD for subscriptions with a React dashboard and basic metrics.

## Installation
bash
git clone https://github.com/he1snber8/SaaS-Subscription-Tracker.git
cd SaaS-Subscription-Tracker


## Usage
bash
# Backend
dotnet run
# Frontend
npm install
npm start


## Implementation Steps
1. Scaffold ASP.NET Core project for subscription CRUD.
2. Add multi-tenant data model and authorization checks.
3. Expose subscription APIs for tenants.
4. Create React dashboard for subscriptions and metrics.
5. Integrate React with ASP.NET Core APIs securely.

## API Endpoints
- /api/subscriptions
